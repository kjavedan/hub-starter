# Hub-Starter API 🚀

Express-based backend using **TS-Rest** for end-to-end type safety.

## 🛠 Features

- **Contract-first**: API is defined in `@hub-starter/contracts`.
- **Validation**: Automatic request/response validation via Zod.
- **Docs**: Auto-generated Swagger UI at `/docs`.
- **Security**: Helmet, CORS, and Rate Limiting included.

## 💻 Development

```bash
pnpm dev
```
Runs the server with `tsx watch`.

## 🧪 Testing

```bash
pnpm test
```
Uses Vitest for unit and integration tests.
