# Hub-Starter Web 🌐

A modern Next.js frontend for the Hub-Starter monorepo.

## 🛠 Features

- **Type-safe Hooks**: Uses `@ts-rest/react-query` generated hooks.
- **Styling**: Tailwind CSS 4 + custom design tokens from `@hub-starter/ui`.
- **Theming**: Light/Dark mode support via `next-themes`.

## 💻 Development

```bash
pnpm dev
```

## 🏗 Build

```bash
pnpm build
```
Generates an optimized Next.js production build.
